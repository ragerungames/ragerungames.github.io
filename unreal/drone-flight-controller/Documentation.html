1. Overview

The plugin is built in three layers:

  • Pilot: who flies the drone. The player (keyboard, mouse, gamepad through Enhanced Input), Drone AI, a flight recording, or your own Blueprint calling Set Pilot Input.
  • Simulation: the Drone Flight component turns stick input into motor thrust on a physics body: motors with spool-up lag, a mixer for any motor layout, drag, ground cushion, prop wash, wind and crashes.
  • Presentation: cameras, HUD, sounds, propeller spin and blur, dust, sparks and smoke.

2. Installation and demos

Enable the plugin (Edit > Plugins > Drone Flight Controller Pro) and restart. It uses Enhanced Input and the engine's Procedural Mesh Component (both switched on automatically). The project should use Enhanced Input as its default input classes; Check & Fix sets this for you.

A Welcome window opens once after installing; it is always available from Tools > Drone Flight Controller > Welcome.

3. Drone Pawn and models

  • Drone Pawn: ready to fly with a simple placeholder quad, collision box, all presentation components, player controls and HUD.
  • Drone Pawn (Custom Model): the same without the placeholder: add your model's meshes under Collision and list the motors.
  • Drone Pawn (Designed): builds its model from a Drone Design (see the Drone Creator).

Create Drone Blueprint (Content Browser, right-click static meshes) makes a Custom Model drone from a model: propellers found by name (prop, rotor, blade, fan, screw) or by shape, pivots at their hubs, motors with alternating spin directions (stacked pairs counter-rotate), a collision box sized to the model and cameras scaled to it. Names with Front and Back / Rear turn the model to face forward.

Pawn settings: key ramp and release, stick dead zone and expo, invert pitch, keyboard layout (Gamer or Transmitter Mode 2), mouse turn, Input Config (your own Enhanced Input assets), HUD style, controls menu, drone name and drone switching.

4. Flight component

Modes

ModeSticksFeel
CinematicSet speed; brakes and holds position when releasedSlow, smooth, precise
SportSet tilt; levels itself; can hold heightFast, leans hard
AcroSet rotation rates; keeps any angleFPV racing, flips

Allow Cinematic / Sport / Acro chooses which modes the player can switch to. States: Disarmed, Armed, Flying, Landed, Crashed. Auto Disarm turns the motors off after landing.

Presets

Beginner, Camera Drone, FPV Racer, Heavy Lifter, Tiny Whoop and Arcade set physics and handling in one go (Apply Preset, or Apply Preset On Start). Arcade ignores wind, ground cushion, prop wash and crashes and carves through turns.

Physics and handling

Physics: mass, thrust-to-weight, frame arm length, motor response and spin-down, idle throttle, yaw authority, top speed, rotor drag, vertical and angular drag, ground effect and its height, translational lift, prop wash, wind sensitivity, arcade, crash speed. Handling: per-mode speeds, tilts, rates, acceleration, drift brake, climb and descent speeds, Acro rates and expo, throttle expo, air mode, absolute throttle, controller strengths.

Motors

Each motor has a position, spin direction, propeller (the component to spin, by name) and spin axis. An empty list flies as an X quad. The mixer works out how hard each motor pushes for any layout (quad, hexa, octo, coaxial).

Useful calls and events

Arm, Disarm, Toggle Arm, Respawn, Respawn At, Place In Air, Set Spawn Point, Crash, Rebuild Physics, Set Thrust Scale, Set Flight Mode, Set Pilot Input; Begin Replay / Replay Step / End Replay. Readouts: state, mode, altitude, speed, climb, heading, throttle, motor RPM and power, tilt, wind, ground effect, prop wash, hover throttle, lift capacity, velocity. Events: State Changed, Flight Mode Changed, Armed, Disarmed, Takeoff, Landed, Crashed, Impact, Respawned, Teleported.

6. Drone Camera

  • Chase: follows behind; look-ahead, speed field of view, travel swing, cargo pull-back.
  • Onboard: Auto (gimbal in Cinematic and Sport, FPV camera in Acro), Gimbal or FPV. Gimbal: tilt and zoom with right mouse and wheel, pan smoothing, horizon lock or lean, auto aim at an AI drone's subject. FPV: tilt, field of view, vibration.
  • Orbit: look around the drone with the mouse, auto turn, zoom.
  • Line of sight: the view of a pilot standing on the ground, with auto zoom.

Walls are avoided, the drone body is hidden onboard, impacts shake the camera (Add Shake from Blueprint), and everything scales to the drone's size.

7. Drone AI

Add a Drone AI component to any drone (or use the Setup Window's quick setups). The AI flies through the same flight model as a player, with obstacle avoidance, separation from other drones, minimum height, auto takeoff and respawn after crashes.

BehaviourDoes
Hover / Land / Move ToHold position / land / fly to a point
Follow / Orbit / ChaseFly with, circle or chase a target
WanderRandom points round its start
WaypointsFly a Drone Waypoint Path (loop, ping-pong, once; stop and wait)
RaceRace a Drone Race Track, braking for corners
Follow-meFilm a person or vehicle from behind and above, hold when it stops, catch up when it runs; aims the gimbal at it
PatrolFly a route, look around, spot targets in its vision cone, follow, search, give up and return; vision cone mesh, awareness

Flight style Smooth (Cinematic mode) or Agile (Sport mode), speed, facing (travel direction, target, keep heading). Return home: with a Drone Battery, any behaviour flies home and lands to charge when low, then carries on. Events report waypoints, arrival, laps, spotting and losing targets, going home and charged.

Formations

A Drone Formation on a leader (or following the player's drone): 8 shapes, spacing, height, rows climbing, followers (or join nearby AI drones), follower style and speed.

Waypoint paths

Drone Waypoint Path is a spline: move points in the level, Alt-drag to add one. Tools > Drone Flight Controller > Create Waypoint Path places one where the viewport looks.

9. Cinematic tools

  • Drone Shot Camera (on every Drone Pawn): Orbit, Tracking, Reveal, Pull-back, Top-down, Fly-by, each with seconds, distance, height, speed and zoom; smoothness, hand-held wobble, auto next, cinema bars, shot names, hidden HUD, wall avoidance. B next shot, C back.
  • Drone Flight Recorder (on every Drone Pawn): K records, L replays on the drone (or on the camera) with smoothing, speed and loop; Save Last Recording / Load Recording use JSON files in Saved/FlightRecordings. With nothing recorded, L flies a sightseeing tour.
  • Drone Camera Path: a camera move along a spline at an even speed, ease in and out, look at a target or along the path or by key rotations, per-point field of view.
  • Drone Shot Sequence: steps of shots, camera paths, chase camera or still camera, with captions, seconds, cuts or fades, a title, cinema bars and a skip hint. It can fly a recorded clip or the tour while it films. Play from Blueprint, on start or with a key.

10. Winch, cargo and delivery

Drone Winch presets: Cargo Bay (stows the parcel tight), Rescue Winch, Parcel Tether, Long Line. Line length, reel speed, strength (snaps when overloaded), hook weight and size, auto hook, lock when raised, swing damping, colours. Z lowers, X raises, V lets go. Tension, slack and state are readable from Blueprint.

Drone Cargo actor: Parcel, Medical Kit, Food Bag, Rescue Buoy, Crate (or the Drone Cargo component on your own actor): mass, grab radius, fragile with bump speed and condition.

Drone Depot: pick-up, drop-off or both, zone size, pad and beacon. Drone Delivery Game: random jobs between depots with a time limit from the distance and the drone's speed, score with time bonus, condition and streak, HUD panel and callouts.

11. Combat

  • Drone Health: team, health, regeneration, respawn delay, spawn protection, crash damage, explosion. Shot-down drones explode, tumble and come back.
  • Drone Weapon: Blaster, Machine Gun, Rockets, Homing Missiles; primary or secondary trigger; fire rate, damage, speed, range, spread, explosion radius, homing, magazine and reload, recoil; fires from the nose or a turret.
  • Drone Turret: Gun Turret (optional missile rails), Missile Pod, Nose Cannon; mount below, on top, at the nose or the sides; turn speed and limits.
  • Drone Aim: crosshair moved by the mouse (screen centre on a gamepad), aim assist, missile lock-on, hit and kill markers.
  • Drone Combat AI: finds enemies in sight range, strafes round them, fires when it can hit, second weapon every few seconds.

The Drone Combat Setup library sets it all up: Make Player Fighter, Make Enemy, Make Practice Target, Add Weapon, Add Turret. Any actor with Drone Health (a target board, a truck) can be shot.

12. Effects and surfaces

Propeller spin and blur (opacity, start, blades hidden at speed, tint), ground downwash per surface (dust, concrete, grass, sand, water spray, snow; set by Physical Material, a Drone Surface component or tags), impact sparks and crash smoke, speed trails from the motors. No particle systems are needed: effects are instanced cards.

13. Sound

The Drone Sound component generates the motor (pitch follows RPM and drone size), whine, air rush at speed, prop wash rumble, impact, crash and landing sounds and arming beeps, so no sound files are needed. Master, motor and impact volumes, distance fade, and custom sound slots for your own sounds.

14. Battery

Drone Battery: hover minutes, drain grows with motor load, voltage sag when low (at empty it can only descend), recharge while disarmed, refill on respawn, infinite. On Low (20% by default) and On Empty events; shown on the HUD.

15. Flight HUD

Compass and heading, speed and height dials with units, climb, flight mode and state, power with the hover mark, per-motor bars, battery, wind, artificial horizon (overlay in the onboard view), physics hints, callouts (Show Callout from Blueprint), race, delivery, sneak, combat and arcade panels, name tags, cinematic bars and titles, key hints. Style: scale, horizon, units, colours and which parts show. H hides the HUD.

17. Wind, race, switching and demo helpers

  • Drone Wind: speed, gusts, gust frequency, turbulence, full strength height; direction = the actor's rotation. Get Wind At for your own effects.
  • Drone Race Gate and Drone Race Track: list gates in order (the first is start and finish), laps, last and best lap, next-gate glow, either-direction gates; events for gates and laps.
  • Drone switching is built into the Drone Pawn: N switches between drones that allow it, O watches the AI drones.
  • Drone Windsock, Drone Name Tag (name and a short line above a drone or place), Drone Demo Walker (a walking figure for follow-me), Drone Sneak Challenge, Drone Demo Menu and Drone Demo Navigation.

18. Setup Window and Check & Fix

Tools > Drone Flight Controller > Setup Window (or the Drone Setup toolbar button). Pages: Overview (drone gallery, make a model a drone, Drone Creator), Drone, Controls, Camera, AI Drones, Combat, Delivery, Effects, Audio, Battery, Scene, Check & Fix, About. Pick a drone under Editing or by selecting it in the level. Every button can be undone.

Check & Fix looks for setup problems once a second: collision, motors and propellers, drones nothing flies, player drones, AI targets and paths, waypoints inside walls, flight styles, battery levels, patrol targets, formations, winch lengths, cargo, delivery depots and cargo, wind, physics substepping and Enhanced Input. Each row has a Fix button; Fix All runs the fixes that need no decision.

19. Blueprint and C++

Everything above is available in Blueprint. Classes start with RR in C++ (for example ARRDronePawn, URRDroneFlightComponent, URRDroneAIComponent).

// Fly a drone from code (no player controls)
Drone->GetFlight()->SetPilotInput(FRRDroneInput{ /*Throttle*/ 0.2f, /*Yaw*/ 0.f, /*Pitch*/ 0.5f, /*Roll*/ 0.f });

// Make an AI drone follow the player
URRDroneAIComponent* AI = Drone->FindComponentByClass<URRDroneAIComponent>();
AI->Follow(PlayerDrone, FVector(-300.0, 350.0, 120.0));

// Build a random designed drone while playing
FRRDroneDesign Design = URRDroneDesignLibrary::MakeStarter(ERRDroneStarter::FPVRacer);
URRDroneDesignLibrary::Randomize(Design, 42, 0);
ARRDroneDesignPawn::SpawnDesignedDrone(this, Design, SpawnTransform, true);

// Give a drone weapons
URRDroneCombatLibrary::MakePlayerFighter(Drone, true);

Editor scripting: Drone Editor functions Create Drone Blueprint, Create Designed Drone Blueprint, Create Input Assets, Open Setup Window, Get Setup Problems, Fix All Setup Problems, Open Drone Creator.

20. Troubleshooting

ProblemFix
The drone does not take offHold Space (or push the left stick up); F turns the motors on. A Battery at 0% can only descend.
Keys do nothingCheck & Fix > Use Enhanced Input; make sure the drone is possessed (Auto Possess Player, or Make It the Player Drone).
My model's propellers do not spinFind Propellers Again (Setup Window > Drone) or name the parts Prop1, Prop2...; import with Combine Meshes off.
The drone wobbles going downThat is prop wash: descend while moving sideways, or lower Prop Wash in Physics.
Flight feels different at low frame ratesTurn on physics substepping (Setup Window > Scene, or Check & Fix).
An AI drone just hoversIt needs a target or a path: Check & Fix lists it with a fix.
Demo maps missing in a packaged gameAdd them to the maps to include in Project Settings > Packaging.
